
Проєкт представляє собою багатофункціональну програму для малювання, розроблену на базі C# WinForms із застосуванням сучасних шаблонів проєктування та принципів чистого коду. Додаток дозволяє користувачу використовувати різноманітні інструменти малювання, такі як лінії, прямокутники, еліпси та вільний пензель, забезпечуючи при цьому динамічне налаштування кольорів та товщини ліній у реальному часі. Важливою особливістю програми є реалізація повноцінної системи скасування та повторення дій Undo/Redo, що базується на збереженні історії команд, а також можливість очищення полотна та стабільна робота логіки.
При розробці було дотримано ключових принципів програмування, серед яких Single Responsibility для розділення логіки між канвасом та фабрикою фігур, а також принцип KISS, що забезпечив прямолінійну та зрозумілу реалізацію методів малювання. Завдяки використанню DRY спільна логіка всіх фігур винесена в базовий абстрактний клас, тоді як принцип інверсії залежностей DIP дозволив головній формі працювати з абстракціями фігур замість конкретних реалізацій, що разом із чітким відокремленням інтересів між шарами Core, Models та UI робить проєкт легким для підтримки.
В архітектурі застосунку впроваджено три важливі патерни проєктування. Патерн Command дозволяє обертати кожну дію малювання в об'єкт для керування історією змін, Factory Method централізує створення об'єктів фігур у спеціалізованому класі ShapeFactory, а патерн Strategy дає змогу гнучко змінювати алгоритм малювання залежно від обраного інструменту
Під час написання коду було застосовано кілька технік рефакторингу для покращення його якості. Складні блоки обробки подій миші були винесені в окремі методи за допомогою Extract Method, а технічні назви змінних замінені на самодокументовані назви, що відображають суть об'єктів. Логіку обчислення координат було перенесено ближче до самих моделей фігур через Move Method, магічні числа в налаштуваннях замінені символічними константами, а використання зрозумілих назв методів зробило код прозорим навіть без великої кількості коментарів.
Для локального запуску проєкту необхідно відкрити файл рішення у Visual Studio та запустити застосунок натисканням клавіші F5.
